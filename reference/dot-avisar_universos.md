# Avisa de las variables cuyo universo cambia entre los censos pedidos

Avisa de las variables cuyo universo cambia entre los censos pedidos

## Usage

``` r
.avisar_universos(variables, anios)
```

## Arguments

- variables:

  nombres armonizados

- anios:

  censos solicitados

## Value

invisible(TRUE); emite un \`cli_warn\` por cada variable afectada
