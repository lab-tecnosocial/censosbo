# Tabla de geografía de Bolivia

Tabla con los 343 municipios de Bolivia y sus códigos geográficos
oficiales del CPV-2024, extraídos del diccionario Redatam del INE.

## Usage

``` r
geo_bolivia
```

## Format

Un data.frame con 343 filas y 6 columnas:

- idep:

  Código de departamento (2 dígitos, con cero a la izquierda)

- nombre_dep:

  Nombre del departamento

- iprov:

  Código de provincia

- nombre_prov:

  Nombre de la provincia

- imun:

  Código de municipio

- nombre_mun:

  Nombre del municipio

## Source

INE Bolivia, CPV-2024. Diccionario de variables Redatam (CEN24.dicX).
