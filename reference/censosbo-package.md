# censosbo: Acceso y Análisis de los Datos del Censo de Bolivia 2024

Proporciona acceso programático a los microdatos del Censo de Población
y Vivienda 2024 de Bolivia (CPV-2024) del INE. Descarga archivos Parquet
preprocesados desde GitHub Releases bajo demanda, los almacena en caché
local y ofrece una interfaz R para filtrar por departamento, provincia o
municipio. Soporta flujos de trabajo estilo dplyr vía Apache Arrow y
consultas SQL vía DuckDB. Incluye un diccionario de variables integrado
con etiquetas en español.
