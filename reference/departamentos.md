# Lista los departamentos de Bolivia

Lista los departamentos de Bolivia

## Usage

``` r
departamentos()
```

## Value

Un data.frame con columnas \`idep\` y \`nombre_dep\`.

## Examples

``` r
departamentos()
#>   idep nombre_dep
#> 1   01 Chuquisaca
#> 2   02     La Paz
#> 3   03 Cochabamba
#> 4   04      Oruro
#> 5   05     Potosí
#> 6   06     Tarija
#> 7   07 Santa Cruz
#> 8   08       Beni
#> 9   09      Pando
```
